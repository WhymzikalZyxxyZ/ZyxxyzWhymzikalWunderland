How to add your art to this gallery

Since this is a static site, adding images is a two-step process:

  1. Put your image files in the /virtuoso/gallery/ folder in the repo.
  2. Add an entry to the GALLERY array at the bottom of this page's <script> block, like:
    { src: '/virtuoso/gallery/my-drawing.jpg', caption: 'My Drawing' }
  3. Commit and push — Porkbun will deploy automatically.

Supported formats: JPG, PNG, GIF, WebP, SVG.
